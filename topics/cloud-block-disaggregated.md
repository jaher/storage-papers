# Cloud, Block & Disaggregated Storage

Cloud and disaggregated storage: Azure Storage, RDMA far memory, CXL memory pooling, and serverless storage.

| Paper | Importance | arXiv | Authors | Published | Added | Summary |
|---|---|---|---|---|---|---|
| Windows Azure Storage: A Highly Available Cloud Storage Service with Strong Consistency | ★★★★★ | https://sigops.org/s/conferences/sosp/2011/current/2011-Cascais/11-calder-online.pdf | Calder et al. | 2011-10-01 | 2026-11-06 | The canonical paper on a production cloud storage service, describing stamps, the partition/stream layers, and how strong consistency, availability, and partition tolerance were co-designed (SOSP '11). |
| FaRM: Fast Remote Memory | ★★★★★ | https://www.microsoft.com/en-us/research/publication/farm-fast-remote-memory/ | Dragojević et al. | 2014-04-01 | 2026-11-06 | Built a shared-address-space in-memory platform on one-sided RDMA with lock-free reads, reaching 160M key-value lookups/sec and founding the RDMA systems literature (NSDI '14). |
| Efficient Memory Disaggregation with Infiniswap | ★★★★★ | https://engineering.purdue.edu/~vshriva/courses/papers/infiniswap_2017.pdf | Gu et al. | 2017-03-01 | 2026-11-06 | The first scalable, decentralized remote-memory paging system, harvesting idle cluster memory over RDMA as a swap device with no application or OS changes (NSDI '17). |
| CORFU: A Shared Log Design for Flash Clusters | ★★★★☆ | https://www.usenix.org/conference/nsdi12/technical-sessions/presentation/balakrishnan | Balakrishnan et al. | 2012-04-01 | 2026-11-06 | Organized a cluster of network-attached flash devices as a single shared log accessed directly by clients, eliminating storage servers from the I/O path (NSDI '12). |
| Using RDMA Efficiently for Key-Value Services (HERD) | ★★★★☆ | https://www.pdl.cmu.edu/PDL-FTP/Storage/herd-sigcomm2014_abs.shtml | Kalia et al. | 2014-08-01 | 2026-11-06 | Showed RDMA reads are the wrong primitive for key-value serving and built a single-round-trip RDMA-write design hitting 26M ops/sec at 5 µs, a template for later RDMA services (SIGCOMM '14). |
| ReFlex: Remote Flash ≈ Local Flash | ★★★★☆ | https://mast.stanford.edu/pubs/reflex_remote_flash_local_flash/paper.pdf | Klimovic et al. | 2017-04-01 | 2026-11-06 | A dataplane OS that serves remote NVMe flash at 850K IOPS/core with only 21 µs over local access plus per-tenant QoS, making disaggregated flash practical (ASPLOS '17). |
| LegoOS: A Disseminated, Distributed OS for Hardware Resource Disaggregation | ★★★★☆ | https://www.usenix.org/conference/osdi18/presentation/shan | Shan et al. | 2018-10-01 | 2026-11-06 | Proposed the splitkernel OS model, disseminating OS functions into per-component monitors so CPU, memory, and storage can be disaggregated independently (OSDI '18 Best Paper). |
| Pocket: Elastic Ephemeral Storage for Serverless Analytics | ★★★★☆ | https://www.usenix.org/conference/osdi18/presentation/klimovic | Klimovic et al. | 2018-10-01 | 2026-11-06 | The first storage system designed for ephemeral serverless data, auto-rightsizing CPU, bandwidth, and capacity across storage tiers to match Redis performance at ~60% lower cost (OSDI '18). |
| AIFM: High-Performance, Application-Integrated Far Memory | ★★★★☆ | https://www.usenix.org/conference/osdi20/presentation/ruan | Ruan et al. | 2020-11-01 | 2026-11-06 | Replaced page-granular swapping with an application-integrated runtime and remotable data structures, beating paging-based far memory by up to 61× (OSDI '20). |
| Pond: CXL-Based Memory Pooling Systems for Cloud Platforms | ★★★★☆ | [2203.00241](https://arxiv.org/abs/2203.00241) | Li et al. | 2023-03-01 | 2026-11-06 | From Azure production traces, the first CXL memory-pooling system meeting cloud performance goals, cutting DRAM needs 7% with 8–16-socket pools (ASPLOS '23). |
| TPP: Transparent Page Placement for CXL-Enabled Tiered-Memory | ★★★★☆ | [2206.02878](https://arxiv.org/abs/2206.02878) | Maruf et al. | 2023-03-01 | 2026-11-06 | An OS-level hot/cold page placement mechanism for CXL tiered memory, merged into Linux 5.18 and deployed on Meta's fleet, improving performance up to 18% over stock Linux (ASPLOS '23). |
| IOFlow: A Software-Defined Storage Architecture | ★★★☆☆ | https://www.microsoft.com/en-us/research/publication/ioflow-a-software-defined-storage-architecture/ | Thereska et al. | 2013-11-01 | 2026-11-06 | The first software-defined storage architecture, decoupling a centralized control plane from data-plane queues to enforce end-to-end I/O policies without VM or application changes (SOSP '13). |
| Flash Storage Disaggregation | ★★★☆☆ | https://www.cs.purdue.edu/homes/csjgwang/CloudNativeDB/FlashDisaggregationEurosys16.pdf | Klimovic et al. | 2016-04-01 | 2026-11-06 | Measured remote flash over commodity networks on real datacenter workloads and showed independent CPU/flash scaling recoups the ~20% remote-access penalty (EuroSys '16). |
| Octopus: An RDMA-Enabled Distributed Persistent Memory File System | ★★★☆☆ | https://www.usenix.org/conference/atc17/technical-sessions/presentation/lu | Lu et al. | 2017-07-01 | 2026-11-06 | Redesigned a distributed file system around a shared persistent-memory pool accessed directly over RDMA, reaching near-raw-device bandwidth (USENIX ATC '17). |
| InfiniCache: Exploiting Ephemeral Serverless Functions to Build a Cost-Effective Memory Cache | ★★★☆☆ | [2001.10483](https://arxiv.org/abs/2001.10483) | Wang et al. | 2020-02-01 | 2026-11-06 | The first in-memory object cache built entirely on ephemeral Lambda functions, using erasure coding and delta-sync backups for 31–96× cost savings vs. ElastiCache (FAST '20). |
| Direct Access, High-Performance Memory Disaggregation with DirectCXL | ★★★☆☆ | https://www.usenix.org/conference/atc22/presentation/gouk | Gouk et al. | 2022-07-01 | 2026-11-06 | The first real CXL 2.0 system, connecting host processors directly to remote memory over CXL.mem with load/store access and no data copies, on FPGA-based hardware (USENIX ATC '22). |
| InfiniStore: Elastic Serverless Cloud Storage | ★★★☆☆ | [2209.01496](https://arxiv.org/abs/2209.01496) | Zhang et al. | 2023-03-01 | 2026-11-06 | Couples a ServerlessMemory layer built from function memory with a persistent object-store layer and parallel recovery, adding durability to the InfiniCache idea (VLDB '23). |
| BPF-oF: Storage Function Pushdown Over the Network | ★★★☆☆ | [2312.06808](https://arxiv.org/abs/2312.06808) | Zarkadas et al. | 2023-12-11 | 2026-11-07 | Pushes storage functions over the network with eBPF, offloading index lookups and scans to remote storage. |


Note: there is no peer-reviewed paper describing Amazon EBS, Azure Managed Disks/Premium Storage, or Google Persistent Disk internals — those designs are unpublished. The closest canonical production-cloud-storage papers are Windows Azure Storage (above) and GFS (filesystems topic).
